# 2. Intermediate Exercises

## 2.1. Additional pipeline features
- Make sure your integration tests run in your pipeline
- Add security scans to your pipeline
- Implement caching for the various tools in your pipeline
- Output reports from your pipeline as GH artifacts

## 2.2. Add additional app features
- Create user authentication features for your app
  - Login
  - Logout
  - Role or User-based access
- Implement API rate-limiting and/or request caching
- Add tests for above features

## 2.3. Parallel jobs
- Reimplent your pipeline as jobs with dependencies instead of steps
